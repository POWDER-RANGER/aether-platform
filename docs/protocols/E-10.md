# E-10 — Recording integrity and replay readiness

**Status:** TOOL IMPLEMENTED; owner hardware execution UNVERIFIED  
**Threshold:** **PROPOSED, NOT FROZEN: 10/10 runs verified and no stream gap > 1 s.**

## MSI procedure

`python -m aether.cli_ext verify-run runs/<run_id>`

Checks manifest presence/parseability, stream timestamp monotonicity and largest gap, frame index monotonicity and correspondence with JPEG files, and events.jsonl parseability. Writes evidence/E-10/<run_id>.json and exits 1 if any check fails. It verifies structural integrity, not semantic correctness or hardware provenance.

## Evidence

`evidence/E-10/<run_id>.json`

Preserve raw samples and linked run files. Do not use synthetic benchmark input as captured gameplay evidence.

## Purpose

Streams and frames are present, monotonic and replayable.

## Record

- Run ID and timestamp; git revision and dirty state.
- ENV and scenario; mode; exact software, Windows, GPU and driver versions.
- Raw timestamps/samples, sample count, summary statistic, and output mode.
- Any interruptions, player override, E-stop, faults, neutral transitions, or missing observations.
